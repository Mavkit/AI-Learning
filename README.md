# AI Agent Engineering

A hands-on, 14-week course for learning modern AI application engineering by
building a production-style research and knowledge agent.

The course covers:

- LLM foundations and model APIs
- Structured outputs and tool calling
- Embeddings, vector databases, and RAG
- Agent harness design
- State, memory, retries, and durable execution
- Layered guardrails and agent security
- Model Context Protocol (MCP)
- Planning and multi-agent systems
- Evaluations, observability, and deployment

The central principle is that an AI model proposes outputs and actions, while the
surrounding harness owns authority, validation, state, execution, and safety.

## Course structure

Each week combines concepts, implementation, controlled experiments, tests, a
knowledge check, and explicit completion criteria. The same project grows from a
small chat client into a guarded and observable agent platform.
